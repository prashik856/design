# Key Memory And Storage Systems
Types of Memory and Storage

## Memory
Memory
- RAM
- ROM

### RAM
Random Access Memory
RAM Stores data temporarily when the program is running.
It is fast.
RAM is volatile. It loses it's memory if there is a no power.

#### SRAM
Static Random Access Memory
Fast and expensive type of RAM used in fast paced applications. (CPU caches)

- CPU Caches
- Faster than DRAM

#### DRAM
Dynamic Random Access Memory.
Slower and cheaper than SRAM.
Needs to be constantly refreshed to retain data. Making it high cost maitainable.

- FPM DRAM
- EDO RAM
- SDRAM
- DDR SDRAM
- GDDR SDRAM

FPM DRAM and EDO RAM are obsolete.

The most famous are DDR SDRAM.

The common types of DDR SDRAM are DDR Variance
- DDR4
- DDR5

GDDR is specail type of RAM used for faster data transferring.
It is used by GPU for massive parallel processing.

- GDDR6
is the most wildly used today.


### ROM
Read only memory
Retains data even when there is no power.
It is non volatile. Used to store essential information like firmware and BIOS.

- firmware
- Bios

#### Firmware
Firmware is a type of software installed in ROM which controls how different hardware devices
communicate with each other.

#### BIOS
Basic Input Output System

The first software computer runs when we power it up.
This software is responsible for starting our computer, initializing hardware components,
and handly over control to the Operating System (OS).


## Storage
Types of Storage
- HDD
- SDD
- USB Drives
- SD Cards

### HDD
Hard Disk Drives
Introduced by IBM in 1956.
Stores data in spinning magnetic disc. large storage capacity at a low price.


### SSD
Solid State Drives

Use NAND Gate flash memories [https://en.wikipedia.org/wiki/Flash_memory#NAND_flash].

They provide fast data access. Reduce power consumption, and increase durability compared to HDDs.
Come at a higher price.

Non Volatile Memory Express (NVME)
NVME is a high performance interface for SSDs that connects directly to CPU via PCIe links.
PCIe (Peripheral Component Interconnect Express solid state drive)
This provides lower latency and significantly faster rate of data transfer compared to standard SSDs.

### USB Drives
Flash Drives or thumb drives.
Small plug and play devices used with any usb port.
Used to easily transfer files between computers.

## SD Cards
SD Card, Mini Card, Micro card.
Used in cameras, smartphones, and are smaller in shape.
