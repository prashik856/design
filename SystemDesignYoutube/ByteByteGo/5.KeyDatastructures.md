# Key Datastructures

## Datastructures

- List - Twitter Feeds
- Arrays - Math Operations on large datasets
- Stack - Undo/Redo of word editor
- Queue - Printer jobs, user actions in games
- Heap - Task Scheduling
- Tree - HTML Document, AI decision
- Suffix Tree - Search string in document
- Graph - Friendship tracking, Path finding
- R tree - Nearest neighbour
- Hash Table - Caching systems

### Lists
Linked Lists

Used for storing ordered data.

Used in task management, Social media feed, and shopping carts.

In Task Management, it can be used to store organized tasks for each user.
Task can be added, removed, or reordered easily.

Used in Social media applications like twitter where they store and display user feed in real time.
latest content is shown in the correct order.

### Arrays
Used when our size of collection is known and doesn't change frequently.

Commonly used in Mathematical Operations [Matrix], Storing large datasets, Or a need to random access
an element.

E.g. For a weather application, we can store the temperatures for a region for a defined period.
We can easily calculate averages and Trend.

Widly used in image processing.


### Stacks
Stacks follow the Last in first out principle.

Best for support Undo and Redo operations in text editors, or maintaining browsing history.

In Text editor, stack can be used to store all changes made to the text. We can easily move 
back to the previous state by an undo operation.

### Queue
Queue operates on a first in first out basis.

Used for managing Printer Jobs, Managing user actions in games, or handling messages in chat applications.

In Chat applications, queue can be used to store messages in the order that they are received.
It insures that messages are properly displayed in correct sequence.

### Heaps
Heaps are used for task scheduling and memory management.

Helpful in implementating priority queues.

We can have Min Heap or Max heap based on the lowest or highest priority items.

### Trees
Trees organize data hierarchically. 

Useful for representating data in natural hierarchy or relationships.

Used in Database Indexing, AI decision making, or file systems.

In AI, decision trees are used for classification tasks.

In Database indexing, we can use trees to speed up search, delete and insert operations.
E.g. B Trees and B+ Trees are commonly used in Relational Databases to efficiently manage and index large amount of data.

### Hash Table
Takes O(N) space.
Hash Table allows for Fast paced searching, insertion and deletion.

They use hash function to generate keys that store value to the corresponding locations.

Hash Tables are majorly used in Search Engines, Caching systems (redis), and in Programming Language Interperters (Compilers).

In search engines, hash tables can be used to quickly fetch cached pages based on key words.
This provides fast search results.

Caching Systems uses hash tables to store and manage cached data.
It allows rapid access to frequently requested data.
Improves overall system performance.

Another use is in Programming Language Interpreters (Compilers).
Compilers use it to efficiently manage variables, functions and other symbols defined in the source code.

### Suffix Trees
Suffix Trees are specilized for searching strings in documents.
Perfect for text editors and search algorithms.

Suffix Trees can be used to efficiently locate all occurances of a search term in a large corpus of text.

### Graphs
Graphs are all about tracking relationships and finding paths.

they are generally used in social network, path finding algorithms and recommendation engines.

In Social network, graph can be used to represent connection between users.
It enables features like friend suggestions, or analyzing network trends

### R Trees
R Trees are good at finding nearest neighbours.

They are really good for mapping apps and Geo Location services.

In Mapping apps, R Trees can be used to store special data such as point to interest.
This is then used for finding nearest location of a search item depending on the users location.


## Cache Friendliness

CPU Cache - Small cache memory between main memory and CPU.
Stores recently accessed data and instructions.

Different data structures have different level of cache friendliness.

Contiguous memory storage data structures like Arrays allow for better cache locality and lower cache misses.
When an array is accessed, cache can store nearby elements anticipating their access.

Linked lists can experience more cache misses. Linked lists are not contiguous memory DS.
They can reduce performance.
Hard for CPU to predict the next node as it is not contiguous.

Trees, Hash tables, and Graphs have varying degrees of cache friendliness based on implementation and use case.

For a high performance application, we need to use a good cache friendly data structure on specific requirements and constraints of the project.
